# Showroom Frontend Agent Instructions

Before making any change anywhere inside `Frontend`, read and follow `Plan.md`.

`Plan.md` is the source of truth for the local frontend coding workflow. It defines the required discovery, requirements, design, task breakdown, implementation, UI quality checks, verification, retest, and final reporting rules for the showroom React/Vite frontend.

The frontend is a React application built with Vite. Keep work scoped to the page, component, hook, context, service, utility, route, or stylesheet required by the user's request.

If a user request conflicts with `Plan.md`, follow the latest explicit user instruction when it is clear and safe. If the conflict could cause destructive changes, broad refactors, route changes, API contract changes, package changes, environment changes, or visual redesign outside the requested scope, ask for clarification before editing.
